## Scope

This repository is the source-code home for Youyixing intelligent quote tools.

## Rules

- Read this repo before editing; follow existing structure once tools exist.
- Keep code changes scoped to the requested tool.
- Do not store secrets, tokens, customer private data, or raw credentials in git.
- Put reusable command notes in `docs/`.
- Put standalone tools under `tools/`.
- Run relevant tests or smoke checks before handing off.

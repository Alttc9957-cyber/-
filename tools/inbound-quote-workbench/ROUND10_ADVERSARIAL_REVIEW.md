# 第十轮对抗式审查报告

审查时间：2026-06-30

审查对象：友易行报价工作台第十轮收口版

## 审查方法

通过浏览器 CDP 直接导入刁钻案例，检查资源匹配、报价计算、提交保存和成交转订单是否真实写入本地状态。

## 导入案例

1. 北京 2 天 4 人：第 1 天大兴机场接机到酒店，第 2 天游览天安门广场、故宫博物院。
2. 同城同车型车辆多候选：同为北京 7 座包车，插入一条空成本和一条 380 元有效成本。
3. 低价接送站干扰：插入北京 7 座接送站 130 元，确认它不会被当作市内包车。
4. 酒店备注成本：插入北京 4 星双床酒店，`internalNotes = 协议价；成本:550`。
5. 门票别名和免费资源：用 `Forbidden City` 匹配故宫博物院，用“天安门”匹配天安门广场免费票。
6. 报价提交和成交：提交报价后返回项目列表，再成交生成订单并刷新本地状态。

## 发现并修复的问题

1. 接送站成本误入按天包车候选。
   - 现象：北京市内用车可能选到 130 元接送站价格。
   - 修复：车辆资源展开时按原始服务类型分配成本，接送机/接送站的 `costPrice` 不再生成包车日用车候选。

2. 空成本参与最低价排序。
   - 现象：空字符串可能被当成 0，排在有效成本前。
   - 修复：新增 `isValidCost()`，候选排序只在有效成本中比价；无有效成本才标记待补价。

3. 门票免费资源和缺成本混在一起。
   - 现象：0 元门票可能被看成缺成本。
   - 修复：新增 `isFree` 标记，天安门广场 0 元作为免费资源正常匹配。

4. 酒店备注成本未被稳定解析。
   - 现象：`协议价；成本:550` 不能稳定进入报价资源。
   - 修复：新增 `extractCostFromText()`，酒店成本优先读取明确成本备注。

## 第二轮关键结果

| 检查项 | 结果 |
|---|---|
| 北京 7 座市内包车 | 选中 380 元有效成本 |
| 北京 7 座接送站 | 选中 130 元接送站成本 |
| 酒店备注成本 | 成功解析 550 元 |
| Forbidden City | 匹配故宫博物院 60 元 |
| 天安门 | 匹配天安门广场 0 元，`isFree=true` |
| 报价汇总 | 成本 2020，参考售价 2525，缺成本 0 |
| 提交报价 | 项目状态保存为“价格已报但未成交”，返回报价项目列表 |
| 成交转订单 | 生成 `OD-R10-ASSERT`，订单状态“已成交待操作” |

## 已知限制

1. 产品库行内编辑采用即时保存，未单独增加“未保存”状态提示。
2. 多候选资源会默认选最低有效成本，并保留候选列表；中置信度候选仍需要 OP 复核。
3. 大交通仍按手动录入成本处理，本轮未做深度订单管理。

# Goals

Goals are module-level delivery contracts.

Use `goals/_template/` to create a goal folder before starting a larger approved module.

Goal files:

- `GOAL.md`: module objective, boundaries, redlines.
- `GOALS.md`: subgoals and execution batches.
- `REPORT.md`: final delivery report.
- `ACCEPTANCE.md`: testable acceptance cases.

Do not use goals to bypass task approval. A goal must map to an approved module or a docs-only planning round.

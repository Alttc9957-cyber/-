# PROJECT_STATUS

日期：2026-07-05

本文记录友易行当前真实项目状态。它用于开工前判断阶段、范围和风险，不替代 `docs/FEATURE_MAP.md` 的详细功能地图。

## 当前阶段

当前项目处于：阶段 0，智能报价系统交付验收 / 稳定化阶段。

判断依据：

- 根目录 `CLAUDE.md` 明确标记当前阶段为阶段 0。
- 现有代码仍是旧版单页工作台形态：`index.html`、`app.js`、`server.js`、`styles.css`。
- 智能报价主流程、产品库、供应商、订单、客户方案已有入口，但大量状态仍依赖浏览器本地存储。
- Supabase 产品库底座已接入一部分，但登录权限、订单、OP、老板看板没有形成正式可交付版本。
- 新增的 domain、Agent Gateway、领域事件模块目前主要是测试边界和未来扩展骨架，尚未接管旧主流程。

## 已经完成的功能

### 智能报价工作台基础流程

- 报价项目列表和项目详情页面已存在。
- 客户资料、服务天数、人数、城市、酒店、导游、用车等字段可录入。
- 可生成和编辑主行程表。
- 可确认线路并生成报价明细。
- 报价明细按用车、导游、门票、酒店、餐、大交通、其他拆分显示。
- 汇总区可计算成本、售价、毛利和缺成本项。

### 产品库数据底座第一版

- 已支持友易行产品库 Excel 模板解析。
- 已能识别线路报价、仅包车报价、导游报价、特色体验价、门票报价、餐、酒店等 Sheet。
- 已生成系统产品库 JSON。
- 已建立 Supabase 产品资源表和服务端查询 API。
- 产品页和报价资源池已优先读取云端已发布产品资源。
- `rawFields` 已作为产品原始字段保留。

### 报价匹配和成本回填第一版

- 用车匹配已包含城市、服务类型、车型、路线候选判断。
- 重庆接机、重庆送机、重庆武隆包车、重庆市内一日游等接口级案例已有验收记录。
- 报价行已保留来源、供应商、匹配状态、匹配原因等字段。

### DeepSeek / 小易助手第一版

## 当前最大技术风险

最大风险是：业务主流程仍集中在 5 万行以上的 `app.js` 中，产品库、报价、供应商、订单、客户方案互相影响。任何直接大改都可能让已能跑通的报价流程回归。

第二风险是：数据源并存。当前同时存在 Supabase 云端产品库、静态系统产品库、浏览器本地覆盖层、供应商本地状态。如果下一轮没有先定义清楚“谁是真源”，仍会出现成本丢失、旧缓存覆盖新数据、客户测试结果不一致。

第三风险是：权限尚未正式落地。`db/schema.sql` 启用了 RLS，但未形成完整 policy；Agent 权限只是浏览器侧骨架，不能当成真正的数据安全机制。

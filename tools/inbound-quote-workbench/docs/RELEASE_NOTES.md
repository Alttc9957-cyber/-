## cloud-product-ui-match-2026-07-03

发布日期：2026-07-03

版本类型：内部验收补丁

对应提交：见 `git log -1 --oneline`

### 本版包含

- 产品资源库页面读取 Supabase 最新发布产品库批次。
- 报价资源池由云端产品库生成，报价行保留云端资源 UUID、供应商、来源和匹配状态。
- 景点门票页面恢复专用字段：类型、票种、淡季成人、旺季成人、旅行社成人、免费政策、保票政策。
- 云端产品库启用时忽略旧本地产品库覆盖层，避免坏缓存污染报价。
- 修复门票正式名和简称重复生成报价项的问题。
- 新增本轮验收报告：`docs/acceptance-cloud-product-ui-match-20260703.md`。

### 已验证

- 云端产品库数量：用车 940、特色体验 77、门票 145、导游 48、酒店 153、餐厅 151。
- 重庆接机 / 送机 7 座成本 250。
- 重庆武隆包车 14 座成本 1500。
- 重庆市内一日游 8 小时 7 座成本 700。
- 北京大兴机场接机成本 260。
- 北京市内用车成本 700，并在多个候选时标记 `need_confirm`。
- 北京英文导游成本 860。
- 故宫博物院门票成人 60、儿童 30。
- 北京酒店返回同城同星级候选。
- 餐厅缺成本显示待补成本，不显示 0。

### 本版不包含

- 不重写报价主流程。
- 不新增订单、权限、飞书同步或 SaaS 模块。
- 不把供应商服务明细迁入云端。
- 不修复客户方案图片/PDF 下载。

### 已知风险

- 餐厅源表缺人均最低成本，当前 151 条餐厅全部为待补成本。
- 供应商服务明细仍在本地状态，后续需要单独入云端并复测成本覆盖。
- 客户方案图片和 PDF 下载仍需单独修复。

### 回退方式

```bash
git revert <本次提交哈希>
```

如需临时停用云端产品库，可删除本机 `.env.supabase.local`，前端会保留静态系统产品库 fallback。

## v0.1.0-baseline-2026-07-02

发布日期：2026-07-02

版本类型：baseline / 内部审查基准

对应 tag：`v0.1.0-baseline-2026-07-02`

对应 commit：`49b2624`

提交信息：`chore: create baseline version for Youyixing project`

### 本版包含

- 报价项目工作台。
- 客户需求输入和小易识别。
- 主行程表、线路生成、线路编辑。
- 产品资源库、产品导入、产品筛选、产品去重、产品导出。
- 供应商管理、供应商导入导出、服务明细。
- 报价明细、成本汇总、缺成本提示。
- 客户方案、多语言、图片/PDF 导出入口。
- AI 模型配置和报价规则设置。
- 当前本地数据、产品库快照、验收报告文件。

### 本版不承诺

- 不承诺产品库导入和报价匹配已全部通过真实 Excel 回归。
- 不承诺图片和 PDF 导出在所有环境可用。
- 不承诺公网静态页具备真实 AI 后端能力。
- 不承诺订单、财务、权限、飞书同步为完整功能。

### 已知风险

- 产品库导入、产品匹配、供应商成本回填仍是 P0 风险。
- 运行日志不足以完整审计 AI 识别过程。
- 静态公网和本地服务能力不同，客户测试需区分环境。
- `app.js` 体量很大，后续修复必须小步提交，避免再次不可追踪。

### 回退方式

只查看 baseline：

```bash
git switch --detach v0.1.0-baseline-2026-07-02
```

把当前分支回退到 baseline：

```bash
git reset --hard v0.1.0-baseline-2026-07-02
```

执行硬回退前必须确认没有未保存改动。

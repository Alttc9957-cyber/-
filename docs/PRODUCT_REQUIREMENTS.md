# 友易行智能报价系统产品需求文档

## 1. 项目背景

友易行旅行社正在开发一套内部使用的 AI 智能报价系统，用于帮助销售和 OP 从客户需求出发，更快完成行程、报价和客户提案。

当前系统已有：

- 报价工作台
- 客户信息
- 行程安排
- 报价项目
- 报价汇总
- 客户提案
- 小易超级报价助手
- 图片素材区
- 系统设置
- API Key 配置

当前主要问题：

- 小易不够智能，更像按钮集合
- 前端 AI 操作较重
- 图片素材区太长
- 英文翻译容易出现中文残留
- 后续需要逐步扩展订单、供应商、老板看板、权限和后台管理

## 2. 产品总目标

将系统逐步升级为：

「友易行旅行社内部销售 + OP + 老板共同使用的 AI 业务工作台」

最终覆盖：

1. 客户需求识别
2. 智能报价
3. 行程生成与优化
4. 英文客户提案
5. 图片素材辅助生成
6. 订单管理
7. 供应商协同
8. 权限管理
9. 老板看板
10. 云部署 / SaaS 化

## 5. 小易 Agent 2.0 需求

小易是当前系统的主要智能入口，展开后默认展示聊天界面。用户可以直接输入自然语言，也可以拖入图片。

第一版支持任务类型：

- `extract_customer_info`：识别客户信息
- `update_customer_info`：更新客户信息
- `generate_itinerary`：生成行程
- `optimize_itinerary`：优化行程
- `extract_quote_items`：识别报价项目
- `check_missing_costs`：检查缺失成本
- `generate_quote_proposal`：生成客户报价提案
- `generate_english_proposal`：生成英文客户提案
- `translate_proposal`：翻译客户提案
- `check_english_chinese_residue`：检查英文方案是否残留中文
- `generate_poster`：生成报价海报或海报方案
- `classify_project_images`：整理 / 分类项目图片
- `save_memory`：保存用户或客户偏好
- `search_memory`：查询历史偏好
- `confirm_apply`：用户确认后应用 AI 建议

AI 输出结构：

```json
{
  "reply": "我已识别到客户想要北京上海 5 天游，是否应用到客户信息？",
  "intent": "extract_customer_info",
  "suggestions": [
    {
      "type": "customer_info_update",
      "summary": "更新客户信息",
      "before": {},
      "after": {},
      "reason": "根据用户输入识别"
    }
  ],
  "actions": [
    {
      "id": "apply_customer_info",
      "label": "应用客户信息",
      "requiresConfirmation": true
    }
  ],
  "attachments": [],
  "memory_suggestions": []
}
```

确认规则：

- AI 不能静默覆盖正式数据
- 所有 AI 输出先成为待确认建议
- 用户点击应用或在聊天中回复确认后，系统才写入正式数据
- 用户可以忽略建议

## 6. 图片素材轻量化需求

客户提案模块保留素材池，但默认只显示摘要：

- 已上传图片数量
- 已确认使用数量
- 待分类数量
- 待补图片数量

展开后支持：

- 查看
- 替换
- 删除
- 分类
- 是否用于客户提案
- 是否作为封面图

图片分类：

- 封面图
- 酒店参考图
- 景点图片
- 餐厅图片
- 行程氛围图
- 其他素材

小易上传图片需要自动同步到当前项目素材池。

## 7. 英文翻译闭环需求

翻译流程：

中文客户提案
→ AI 英文翻译
→ 套用术语库
→ 生成英文预览
→ 人工编辑 / 人工确认
→ 中文残留检测
→ AI 局部修正中文残留
→ 用户最终确认
→ 沉淀修正词汇到个人英语词库 / 公司术语库

术语优先级：

1. 当前客户 / 项目级修正
2. 当前用户个人英语词库
3. 公司术语库
4. 系统默认术语库
5. AI 自由翻译

基础术语包括：

- 费用包含 = Inclusions
- 费用不含 = Exclusions
- 报价有效期 = Quotation Validity
- 酒店或同级 = Hotel or Similar Standard
- 私家团 = Private Tour
- 司导服务 = Driver and Guide Service
- 门票需实名预约 = Tickets require real-name reservation
- 行程以最终确认为准 = The itinerary is subject to final confirmation
- 不含国际机票 = International flights are not included
- 参考酒店 = Reference Hotel
- 最终酒店以确认为准 = Final hotel is subject to confirmation

## 8. 本轮验收标准

1. 项目中新增 `docs/PRODUCT_REQUIREMENTS.md`
2. 小易展开后默认是聊天界面
3. 小易支持自然语言输入
4. 小易支持拖拽 / 点击上传图片
5. 小易能显示已上传图片缩略图
6. 小易上传的图片进入当前项目素材池
7. 素材池默认折叠，不再拉长页面
8. 小易能识别生成客户提案、生成英文提案、生成海报方案、整理图片、检查缺失成本、翻译提案、检查中文残留等任务
9. AI 输出不直接覆盖正式数据，而是生成待确认建议
10. 用户确认后，系统才应用建议
11. 小易支持基础记忆确认和保存
12. 翻译功能支持术语库
13. 英文提案支持中文残留检测
14. 中文残留可以局部修正
15. 用户人工修正后的词汇可以加入个人英语词库
16. 中文源提案和英文预览分开保存，不互相覆盖
17. 整体前端比之前更轻，不再堆满按钮和图片卡片

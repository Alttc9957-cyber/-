# Youyixing Quote System

Source repository for Youyixing intelligent travel quote tools.

## Purpose

This repo stores runnable code for the inbound travel quote system and related internal tools.
Project notes, customer context, and planning docs stay in the Obsidian workspace; source code lives here.

## Working Rules

- Keep source code in this repository before iterating on tools.
- Keep product notes and handoff docs in the Obsidian project workspace.
- Add each tool under `tools/` unless a larger app structure becomes necessary.
- Document setup, commands, and assumptions in `docs/`.
